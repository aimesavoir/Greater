Greater — Help & User Guide

What is Greater?

Greater is a disk-usage analyzer for Windows. It scans your drives fast, shows you exactly what is taking up space, and gives you safe tools to reclaim it — find junk files, locate duplicate copies, and see a breakdown of your data by file type.

It runs entirely on your PC. Nothing is uploaded anywhere. It does not require administrator rights for normal use; elevation is only ever needed to reach locked system areas (a badge in the top-right shows when it is elevated).

The four tabs

The app is split into four sections, reachable from the tab bar under the header:

  • Explorer — scan a folder or drive and browse every file, largest first. This is the main "what is eating my space" view.
  • Clean — scan for known junk (temporary files, caches, update leftovers) and delete it to reclaim space.
  • Duplicates — scan for byte-identical files and delete all but one copy of each group.
  • Statistics — scan a drive and see how its space is split by file type (images, videos, audio, documents, archives, executables, code, other).

Getting started (Explorer)

  1. Hover a drive card at the top and click its overlay button, or type a path (e.g. D:\Games) in the path box.
  2. Press Scan. A progress bar and live counts appear while it walks the tree.
  3. When it finishes, the list shows files largest first with a size bar for each. Use Load more to page through, or the search/filter controls to narrow it.
  4. Hover any row for per-file actions: info, open location, move to Recycle Bin, delete permanently.

The six tiles above the list summarize the scan: files found, total size, elapsed time, the largest file, the average file size, and the deepest path.

Scanner modes (the dropdown next to the path)

  • fast (parallel) — recommended. Uses the native Windows fast-find API across many threads. Typical full C: scan: a few seconds.
  • simple (single thread) — same API but one thread; slower, useful to compare.
  • portable / baseline — generic directory-read fallback that works on any filesystem; slower. Use if the fast modes miss something.

Reparse points (symlinks, junctions, mount points) are never followed or counted, so a scan cannot loop or double-count through them.

Clean tab — reclaiming space

Clean scans for junk: files Windows and apps regenerate anyway (temp folders, caches, update leftovers, logs, thumbnails). Files are grouped into two categories:

  • safe — no user data; regenerable scratch. Preselected.
  • optional — reversible, but costs a re-download or rebuild (e.g. a game shader cache). Opt in if you want the extra space.

Each row shows a reason badge explaining why it is junk. Then:

  1. Use the filter chips (all / safe / optional) and select all/none to choose what to remove.
  2. Watch the live "selected" total (count + size) update as you tick.
  3. Click Move to Recycle Bin (reversible) or Delete permanently. A confirmation warns you first.

Very large files cannot fit in the Recycle Bin and are removed permanently even when you choose "Recycle Bin" — the confirmation dialog reminds you of this.

Files that are in use, or owned by the system without elevation, are skipped and reported as "still present (in use or access denied)".

Duplicates tab — removing duplicate copies

  1. Hover a drive card and click Find duplicates.
  2. Set a smallest file floor (default 1 MB) so tiny files are ignored, and pick a keep heuristic: oldest, newest, or shortest path.
  3. Only files whose size is shared with another file are content-hashed, so the scan is fast. Groups are sorted by how much space deleting the extras would free.
  4. Each group lists every copy. The star marks the copy that will be kept — click a different copy to keep that one instead.
  5. Click Move to Recycle Bin or Delete permanently. Exactly one copy per group is always kept; the last copy can never be deleted.

Files are compared by content, not by name or timestamp — differently-named or differently-dated files with identical bytes are still detected as duplicates.

Statistics tab — space by file type

  1. Hover a drive card and click Analyze.
  2. When it finishes, files are bucketed by extension into: Images, Videos, Audio, Documents, Archives, Executables, Code, and Other.
  3. A stacked bar shows each category's share, and a legend lists every category with its size, a mini bar, the percentage, and the file count.

The mini bars are filled relative to the whole disk's capacity, so you can see how much of the drive each type occupies. Hover a row for exact numbers.

Understanding the numbers

  • scanned / files — how many files were found.
  • total size — combined size of everything found.
  • elapsed — how long the scan took.
  • size bar — the green bar on each row shows a file's size relative to the biggest file in the list, so outliers stand out.
  • reclaimable — space you would free by deleting the current selection.

Safety & privacy

  • Nothing leaves your machine — no telemetry, no network calls.
  • Deleting can go to the Recycle Bin (recoverable) or be permanent. When in doubt, use the Recycle Bin.
  • Protected system files (pagefile, hiberfil, boot configuration, System Volume Information) are never touched.
  • Every destructive action asks for confirmation first, and bulk deletes show exactly what will be removed.

Tips

  • Scans are cancellable at any time — the partial results stay on screen.
  • Only the file list scrolls; the controls stay in place as you resize the window.
  • Live-churn differences of a fraction of a percent between scans are normal — files change while Windows runs.
  • For a huge drive, start with Statistics to see the big picture, then Clean and Duplicates.

Glossary

junk
Regenerable files (temp, caches, logs) that can be deleted to free space.
reparse point
A symlink/junction/mount point. Greater never follows these.
hardlink
Two names pointing at one file on disk. Counted once, never treated as duplicates.
reclaimable
Space that would be freed if the currently selected items are deleted.
elevated
Running with administrator rights, needed only to reach locked system files.
